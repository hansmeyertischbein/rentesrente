# Rentesrente

Kalkulatorer og forklaringer om sparing, lån og investering for unge voksne i Norge. Publiseres på [rentesrente.no](https://rentesrente.no).

## Kom i gang

```sh
npm install
npm test          # regnefunksjonene og satsene
npm start         # forhåndsvisning på http://localhost:8080
npm run build     # bygger siden til _site/
```

Instruksen for Claude ligger i [CLAUDE.md](CLAUDE.md), og designsystemet i [design/](design/).
